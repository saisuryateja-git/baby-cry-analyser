Baby Cry Analyser
An ML-powered classifier that identifies the reason behind infant cries — hunger, pain, discomfort, and more.
Built in 24 hours at Tensor V2.0 Hackathon, Udhgam 2.0 (Woxsen University, Feb 2026) by Team TRACELESS.
Tech: Python · Librosa · Pandas · Scikit-learn · Kaggle (Baby Cry Sense Dataset)
